# Web Migration

This directory tracks the migration from the Flutter passenger‑app and
driver‑app to two installable Progressive Web Apps.

| Document             | Purpose                                                         |
| -------------------- | --------------------------------------------------------------- |
| [PLAN.md](./PLAN.md) | Single source of truth — architecture, decisions, 28‑PR roadmap |

The Flutter apps remain in `passenger-app/` and `driver-app/` until the
migration is complete; they will get a deprecation banner in the final PR.
